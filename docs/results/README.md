# Benchmark output

Raw `wh_bench` CSV files behind the tables in the main README, measured on a
13th Gen Intel Core i7-13620H (Windows 11, Release build, one thread):

- `results_30x20.csv`: `wh_bench --seeds 100 --robots 10 --size 30x20`
- `results_40x30.csv`: `wh_bench --seeds 100 --robots 20 --size 40x30 --density 0.4`
